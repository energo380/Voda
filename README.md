# Voda — распределение общего по колонкам и потребителям

Сайт (GitHub Pages) + Google Таблица. Устроено так же, как сайт заявок
(snabgenie): страница `index.html` общается со скриптом Google Apps Script.

## Как считает таблица

* **Общее** — вводите число (например, 30 000).
* **Колонки №1, №2, №4, №3, №6, №5** — итог каждой можно ввести, а можно
  оставить пустым. Пустые колонки получают остаток
  (общее − введённые колонки) по своим долям — они показаны
  **серым курсивом**. Вводите колонки по очереди (Enter — к следующей);
  последняя оставшаяся колонка сама получает то, что осталось.
* Ввести колонки на сумму **больше общего нельзя**: клетка краснеет,
  под ней пишется максимум, а кнопка «Сохранить» не работает, пока
  ошибка не исправлена. Если введены все колонки, а в сумме не хватает до
  общего, тоже будет ошибка.
* **Строки 1…25** — каждая колонка раскладывается по строкам по весам
  строк. Округление сделано так, что сумма клеток колонки **всегда точно**
  равна итогу колонки, а «Сумма по строкам» + нераспределённые колонки =
  общее, без расхождений в 1–3 единицы.
* **«Не распределять»** — галочка под колонкой. Такая колонка есть только
  в строке «Общее», в строки она не попадает (как №5 в ваших примерах:
  30 000 = 29 957 по строкам + 43 у №5).
* Если общее не ввести, оно считается как сумма колонок.
* «Общее» и все колонки одной ширины; нераспределяемая колонка выглядит как
  остальные — пустые клетки в строках и звёздочка `*` в заголовке.

## Шильдик «Отчёт за» и постоянная надпись

* Вверху листа — шильдик **«Отчёт за: месяц, год»**. По умолчанию текущий
  месяц. Месяц сохраняется в журнал, печатается справа от заголовка,
  а в журнале расчёты отсортированы по месяцам. На листе «Таблица» это
  клетка рядом с датой (формат «ноябрь 2026»).
* **Постоянная надпись** под таблицей вводится только в Google Таблице:
  лист «Настройки», столбец **I**, клетки **I9…I13** (до 5 строк). Она
  видна всегда — на сайте, на листе «Таблица» и при печати. Выводы
  (3 строки) по-прежнему пишутся на сайте для каждого отчёта отдельно.

## Пароли и права

Два пароля лежат в Google Таблице, лист **«Настройки»**, клетки **B5** и **B6**.
При первой установке `setup` придумывает их сам (6 цифр) и показывает
во всплывающем сообщении — поменяйте на свои, когда удобно.

| | Пользователь | Администратор |
|---|---|---|
| Создать расчёт, сохранить | ✓ | ✓ |
| Поправить и пересохранить **свой** только что сохранённый расчёт | ✓ | ✓ |
| Печать | ✓ | ✓ |
| Журнал: смотреть, открывать старые расчёты | — | ✓ |
| Удалять расчёты | — | ✓ |
| Менять чужие записи журнала | — | ✓ |

Проверка прав идёт в скрипте таблицы, а не только на сайте: даже зная
адрес, пользователь не прочитает и не удалит журнал. Если обе клетки
паролей пустые — сайт открыт всем с правами администратора.

Веса строк и доли колонок по умолчанию взяты из трёх ваших примеров
(30 000 / 35 000 / 10 000) и воспроизводят их до единицы округления.

## Установка

### 1. Google Таблица
1. Создайте пустую Google Таблицу.
2. **Расширения → Apps Script**. Удалите всё в `Code.gs`, вставьте
   содержимое файла [`apps-script/Code.gs`](apps-script/Code.gs), сохраните.
3. Выберите функцию **`setup`** → **Выполнить** → разрешите доступ.
   Появятся листы:
   * **Таблица** — сама таблица. Жёлтые клетки — ввод: 3 строки описания
     сверху, дата, «Ввод итога» (общее и колонки), галочки «Не
     распределять», 3 строки выводов снизу. Меняете — лист пересчитывается сам.
   * **Настройки** — название, знаков после запятой, пароли пользователя (B5) и администратора (B6),
     список строк (№, описание, вес) и колонок (имя, доля, «не распределять»
     по умолчанию). После правки — меню **💧 Вода → Перестроить лист**.
   * **Журнал** — сохранённые расчёты, новые сверху.
4. **Начать развёртывание → Новое развёртывание → Веб-приложение**.
   Выполнять как: **Я**, доступ: **Все**. Скопируйте адрес `…/exec`.

### 2. Сайт
1. В `index.html` найдите строку `const API_URL = '';` и вставьте адрес
   между кавычками.
2. В репозитории: **Settings → Pages → Deploy from a branch → main / (root)**.
   Сайт будет по адресу `https://energo380.github.io/Voda/`.

Пока `API_URL` пустой, сайт тоже работает, но расчёты хранятся только
в этом браузере.

### Обновление скрипта
С версии 1.1 на 1.2: вставьте новый `Code.gs`, выполните `setup` ещё раз —
появится блок «Постоянная надпись», а у №5 снимется галочка «не
распределять» и появится доля 0,1627 %. Затем обновите развёртывание.

С версии 1.0 на 1.1: вставьте новый `Code.gs`, выполните `setup` ещё раз
(данные не пропадут — добавится второй пароль), затем обновите развёртывание.

Вставили новую версию `Code.gs` → **Начать развёртывание → Управление
развёртываниями → ✎ → Версия: новая → Развернуть**. Адрес не меняется.

## На сайте
* **Дата** — вводится цифрами (точки ставятся сами) или из календаря 📅.
* **Сохранить** (Ctrl+S) — пишет расчёт в лист «Таблица» и в «Журнал».
  Если расчёт открыт из журнала — обновляет эту запись;
  **＋ Как новый** — сохраняет отдельной записью.
* **Журнал** (только администратор) — открыть или удалить прошлые расчёты.
* **Выйти** — сменить пользователя.
* **Печать** — лист A4: заголовок, 3 строки описания, дата, таблица,
  пометка о нераспределённых колонках, выводы. Кнопки и поля ввода
  на печать не выходят.
* **Колонки — авто** — стирает введённые итоги колонок, остаётся общее.
* Несохранённые изменения не теряются при закрытии страницы — они
  восстановятся при следующем открытии.

## Файлы
* `index.html` — сайт целиком (одна страница).
* `apps-script/Code.gs` — скрипт Google Таблицы.
* Расчёт (блок `CALC START … CALC END`) в обоих файлах одинаковый —
  при правке меняйте его в обоих местах.
